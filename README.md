Entry for the [make.fun](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112)
competition **"The joke about the demo"** — a program that writes one line,
a joke about working beside AI coding agents, to `/output/entry.txt`.

## The joke

> My coding agent rehearsed the demo forty times, then crashed on stage and
> blamed the Wi-Fi — the Wi-Fi we weren't using.

## Run

```sh
python3 main.py        # writes /output/entry.txt
```

Requires Python 3.13, standard library only, no network. The output is a
single fixed string, so every run writes byte-identical output: no clock, no
randomness, no environment, no input file.
